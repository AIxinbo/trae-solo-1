# FC·INTELLIGENCE 数智绿茵平台 — 开发计划文档

> **版本**: v2.0  
> **更新时间**: 2026-08-12  
> **项目定位**: 体育俱乐部智慧管理平台（约 300 人使用，未来扩展至小程序/App）  
> **团队技术栈**: Java + Python + 前端

---

## 一、项目概述

### 1.1 项目背景

针对体育俱乐部用户（约 300 人使用），打造一个数据驱动的足球智慧平台，集成战术看板、赛事指挥、训练计划、球员档案与 AI 参谋功能。系统需支持未来扩展至小程序、App 端，并包含智能体开发、视频 AI 分析等高级能力。

### 1.2 核心目标

- 让每一次首发、换人、训练计划都有数据支撑
- 战术看板支持 2D/3D 切换、自定义阵型、名帅战术库
- 球员档案可编辑能力分值（进攻、传球、定位球、防守等）
- 每个阵型显示由球员能力综合算出的总分
- AI 参谋辅助教练决策

## 三、数据库设计

### 3.1 数据库管理方式

- **PostgreSQL**: 主数据库，存储所有业务数据（15 张表）
- **Redis**: 缓存热点数据、用户会话、实时通知
- **MinIO**: 存储视频、图片等大文件
- **Milvus**: 存储向量数据，用于 AI 语义检索

初始化脚本 `football-deploy/sql/init.sql` 会在 PostgreSQL 首次启动时自动执行。

## 七、部署方案

### 7.1 Docker Compose 文件说明

| 文件 | 用途 | 启动命令 |
|------|------|----------|
| docker-compose.yml | 基础配置（所有服务基线） | `docker-compose up -d` |
| docker-compose.infra.yml | 仅基础设施（PostgreSQL/Redis/MinIO/Milvus） | `./scripts/deploy.sh infra` |
| docker-compose.dev.yml | 全栈开发模式（源码挂载 + 热重载） | `./scripts/deploy.sh dev` |
| docker-compose.prod.yml | 生产环境（打包镜像 + HTTPS） | `./scripts/deploy.sh prod` |

### 7.2 快速启动

```bash
# 1. 准备环境变量
cd football-deploy
cp .env.example .env
# 编辑 .env，修改密码和密钥

# 2. 启动基础设施（独立开发前端或后端时用）
./scripts/deploy.sh infra

# 3. 全栈本地开发
./scripts/deploy.sh dev

# 4. 生产环境部署
./scripts/deploy.sh prod
```

### 7.3 其他命令

```bash
./scripts/deploy.sh stop              # 停止所有服务
./scripts/deploy.sh clean             # 停止并清理所有数据卷（谨慎）
./scripts/deploy.sh logs              # 查看所有服务日志
./scripts/deploy.sh logs backend      # 查看指定服务日志
```
